# 儿童英语闯关应用

这是一个基于 `Python3 + Flask + SQLite` 的儿童英语学习闯关应用。

## 功能

- 关卡学习：句子匹配、翻译选择、动画视频观看
- 闯关记录：查看所有关卡和完成记录
- 设置页面：新增和编辑关卡内容、翻译选项、视频链接
- 浏览器语音输入：支持英文语音录入答案

## 运行方式

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 启动应用：

```bash
python app.py
```

3. 浏览器打开：

```text
http://127.0.0.1:5000
```

## 说明

- 首次启动会自动创建 `english_game.db` 并写入示例关卡。
- 为了让视频可以直接嵌入，建议在设置页面填写支持嵌入的链接，例如 YouTube embed 链接。
- 语音识别依赖浏览器能力，推荐使用新版 Chrome 或 Edge。
